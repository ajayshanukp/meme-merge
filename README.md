Meme Merge 🎮

A physics-based emoji merging game where simple drops turn into chaotic chain reactions.

link https://ajayshanukp.github.io/meme-merge/
---

Overview

Meme Merge is a browser-based game inspired by merge mechanics, enhanced with real-time physics and dynamic interactions.

Built using Matter.js, the game challenges players to strategically drop and combine emoji balls, creating higher-tier merges while managing space and avoiding overflow.

---

Gameplay

- 🎯 Drag to aim
- 🖱️ Click / Tap to drop
- 🔗 Merge identical emojis to evolve
- ⚠️ Avoid crossing the danger line

---

Features

- ⚙️ Physics-Driven Mechanics
  Realistic gravity and collision using Matter.js

- ✨ Visual Effects
  Particle bursts, glow effects, and smooth animations

- 🔊 Interactive Sound System
  Feedback for drops, merges, and game over

- 💾 Auto-Save Progress
  Game state stored locally

- ⚠️ Dynamic Danger System
  Timed failure detection adds tension

- 📊 Score Tracking
  Real-time score and high score system

---

Tech Stack

- HTML5 Canvas
- CSS3 (Glassmorphism UI + animations)
- JavaScript (Vanilla)
- Matter.js (Physics Engine)

---

How to Run

git clone https://ajayshanukp.github.io/meme-merge/
open meme_merge_2048.html

Or simply open the ".html" file in your browser.

---

Game Logic

- Tier-based merging system (progressive emoji levels)
- Collision-based merging using physics engine
- Real-time rendering and animation loop
- LocalStorage integration for saving progress
